# Soluciones Financieras — Versión 2

Incluye:
- Landing page responsive.
- Identidad naranja/blanco inspirada en la pieza suministrada.
- Productos: libre inversión, libranza, compra de cartera y refinanciación.
- Simulador de cuota mensual.
- Conversión de tasa efectiva anual a tasa efectiva mensual equivalente para el cálculo.
- Formulario que abre WhatsApp con mensaje prellenado.
- FAQ, requisitos, proceso, beneficios y CTA.
- WhatsApp flotante.

## Ejecutar localmente
Abrir `index.html` directamente en el navegador.

## Importante antes de publicar
1. Sustituir cualquier dato comercial provisional por las condiciones reales.
2. Definir las tasas, montos, plazos, seguros, comisiones y demás costos reales.
3. Revisar legalmente la publicidad y el tratamiento de datos personales.
4. Crear páginas reales para política de privacidad, tratamiento de datos y términos.
5. Confirmar si Soluciones Financieras es intermediario, operador, corresponsal o entidad vigilada y ajustar los textos.
6. El simulador es orientativo: no representa una oferta ni una aprobación.
7. No solicitar cédulas ni documentos sensibles mediante este formulario; usar un canal autorizado y seguro.
